KOPILKA AI — Telegram-бот для планирования накоплений

Что умеет:
- создавать финансовую цель и срок;
- считать ежедневный и недельный темп накоплений;
- добавлять внесённые суммы;
- показывать прогресс и остаток;
- хранить данные в локальной SQLite-базе.

ВАЖНО:
Бот не подключается к банку и не переводит деньги. Все суммы пользователь вводит сам.
Токен бота — секретный ключ. Не отправляй его в чат и никому не показывай.

Запуск:
1. Установи Python 3.10 или новее.
2. Открой BotFather в Telegram, создай бота командой /newbot и скопируй токен.
3. В папке проекта создай файл .env на основе .env.example и вставь токен.
4. Установи зависимости: pip install -r requirements.txt
5. Установи переменную окружения BOT_TOKEN (см. ниже) и запусти: python bot.py

Windows PowerShell:
$env:BOT_TOKEN="ТВОЙ_ТОКЕН"
python bot.py

Linux/macOS:
export BOT_TOKEN="ТВОЙ_ТОКЕН"
python bot.py

Чтобы бот работал 24/7, его нужно разместить на постоянно работающем хостинге.
Обычный запуск на компьютере прекращается, когда компьютер выключен.

Управление запуском из ChatGPT:
Обычное сообщение ChatGPT само по себе не может включить процесс на твоём ПК или сервере.
Для запуска по фразе «запусти бота» потребуется отдельная защищённая автоматизация/серверный сервис.
